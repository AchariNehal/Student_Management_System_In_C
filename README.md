
# 🎓 Student Management System in C

A simple console-based **Student Management System** developed in C using file handling to manage student records.

## ✨ Features

* ➕ Add students
* 🗑️ Delete students
* 👀 View students
* 🔍 Search students by ID
* 💾 Store records in `students.txt`

## 🛠️ Technologies

* C
* Structures
* File Handling
* File I/O

## ⚙️ Compile & Run

```bash
gcc main.c -o student_management
student_management.exe
```
